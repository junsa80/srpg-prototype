# 밸런스 시뮬 측정 규격 (`tests/sim_test.gd`)

모든 장별 승률은 아래 조건으로만 비교한다. 조건이 바뀌면 결과를 새 기준선으로 따로 기록한다.

| 항목 | 값 |
|---|---|
| 실행 | `SIM_TRIALS=96 SIM_ONLY=<장> $G --headless res://tests/sim_test.tscn -- --flowtest` (장별 병렬, 장마다 격리된 `XDG_DATA_HOME`) |
| 판 수 | 장당 **96판** (2026-10-25 곡선 작업 기준. 기본값 16판은 ±12%p 흔들려 비교용으로 쓰지 않음) |
| 시드 | 판 번호 t = 0..95, `BattleManager.rng.seed = 1000 + t*7919 + "<장>".hash()` (같은 맵이면 결과 재현) |
| 난이도 | 보통 (`Campaign.reset()` → difficulty 0, enemy_lv 0, 환생/노가다 0, 스마트 AI 꺼짐) |
| 성장 | `Unit.fixed_growth = true` (성장률 기대값만큼 고정 성장, 운 없음) |
| 아군 명단 | 시작 멤버 + `PLAN[장][2]`의 영입 유닛 (아래 표). 출전은 맵 `default_deploy`/자동 |
| 아군 레벨 | `PLAN[장][0]`. 전직 표시(true)면 Lv10까지 올린 뒤 전직하고 다시 그 레벨까지 |
| 장비 | 병종 기본 장비 + `PLAN[장][1]` 단계 무기 1개씩 (강철: 강철검/강철창/강철활/썬더/철도끼, 은: 은검/은창/은활/엘파이어). 무기 경험 70(Lv5+ 또는 전직), 은 단계면 120 |
| 아군 AI | 적과 같은 전술 AI(`EnemyAI.plan`) + 안전 검사(예상 피해가 HP 미만, 아린은 HP 50% 미만인 칸만), 회복 담당은 HP 50% 미만 아군 우선 회복, 아린은 3턴부터 제압/탈출 칸으로 이동, 도적·열쇠 보유자는 탈출 맵에서 문 우선 |
| 승리 판정 | 30턴 안에 클리어 보고(`clear_report`)가 나오면 승리. 평균 턴은 승리 판만, 평균 사망은 전체 판 |
| 한계 | 사람보다 거칠다(초반 소수 유닛 장은 특히 낮게 나옴). 방어전(4A·7장)은 생존만 보므로 맵 변화에 둔감. 같은 규격 안에서 상대 비교용 |
