# SRPG 프로토타입 (Godot 4.3, GDScript)

- 인수인계: [HANDOFF.md](HANDOFF.md) · 스토리 요약: [STORY.md](STORY.md) (스포일러 주의) · 변경 이력: [CHANGELOG.md](CHANGELOG.md)
- 플레이: https://junsa80.github.io/srpg-prototype/

고전 파이어엠블렘 스타일 사각 그리드 전술 RPG 뼈대입니다. **휴대폰 세로 화면(720x1280, stretch canvas_items/expand), 터치 전용 조작** 기준입니다.

## 실행
- 에디터: Godot 4.3 이상에서 `project.godot` 열기 → F5
- 헤드리스 자가 테스트: `godot --headless --script res://tests/selftest.gd`
- 웹 빌드: `godot --headless --export-release Web build/web/index.html`
  (스레드 지원 OFF → COOP/COEP 헤더 없는 일반 정적 호스팅에서도 동작)
- 로컬 확인: `python3 -m http.server -d build/web 8000` 후 휴대폰/브라우저로 접속

## 조작 (터치)
1. 아군 유닛 탭 → 파란 칸(이동), 빨간 칸(공격 범위) 표시
2. 파란 칸 탭 → 이동
3. 적 탭 → 하단에 전투 예측(전/후 HP, 데미지, 명중, 추격 x2)
4. **확인** = 공격/대기, **취소** = 이동 취소, **턴 종료** = 적 페이즈
- 선택 안 한 상태에서 적 탭 → 이동/공격 범위와 **다음 행동 의도** 표시
- 대화: 화면 탭으로 진행, 우상단 **건너뛰기**

## 세이브
챕터 시작과 매 플레이어 턴 시작에 슬롯 0으로 자동 저장. `save_N.json.tmp`에 쓰고 rename. 클라우드 충돌 시 자동 선택하지 않고 두 세이브를 나란히 보여주고 고르게 하는 설계(주석 참고).

## 개인 스킬 / 무기 / 지팡이
- `scripts/skills.gd`: 36개 개인 스킬(유닛 이름 기준). 34개 구현, 잭(보물 탐지)·릴리(해제 범위)는 해당 시스템이 없어 데이터만 있음
- `data/weapons.gd`: 무기 14종(위력/명중/치명/무게/내구), 클래스별 기본 장비. 내구는 공격마다 1 감소, 0이면 파손
- 공속 = 속도 − max(0, 무게 − 힘(마법은 마력))
- 지팡이: 이동 후 다친 인접 아군 탭 → 회복량 미리보기 → [확인]. 회복량 = 지팡이 회복 + 마력, EXP 11
- 소지품(내구 포함)은 Campaign 로스터에 저장되어 패배 후 재도전에도 유지
- 테스트: `godot --headless --script res://tests/skills_test.gd`, `godot --headless res://tests/flow_test.tscn -- --flowtest`

## 거점 / 보급 / 2장 (최신)
- 흐름: 1장 클리어 → 거점(상점·수송·장비·출전·출격) → 2장 「숲을 지나 폐허 요새」
- 골드: 장 클리어 보상(1장 1000G, 2장 1500G) + 일부 적 처치 시 골드, 보물상자
- 상점: 철/강철 무기·힐 구입(수송대로 보관), 은 무기·멘드는 2장 클리어 후
- 수송대: 공용 창고. 전투 중에는 아린 선택 → [수송]
- 장비: 장착 무기 선택, 다른 유닛에게 주기, Lv10 전직(새 무기 종류 + 해당 철 무기 1개 지급)
- 전투 중 [무기]: 사거리에 맞는 무기가 2개 이상이면 바꾸며 예측 갱신
- 적 드롭(노란 표시): 처치한 아군에게, 소지품 5칸이 차면 수송대로
- 2장: 12x20 맵(드래그로 화면 이동), 숲 접근 + 요새(방어+2 회피+20, 턴마다 20% 회복), 보스 그림자 지휘관(옥좌 고정), 적 9명, 5턴 옆문 증원(4턴부터 경고 표시), 잠긴 문/보물상자(도적·루크, 릴리=문 2칸, 잭=상자 원거리+300G), 에일린·레온 합류
- 연출: 이동 경로 화살표, 타일 단위 이동, 애니 커서, 지형/유닛 창, 페이즈 배너, 위험 범위 토글, 측면 전투 화면(HP 감소·치명 플래시·화면 흔들림·데미지 숫자·EXP·레벨업), 연출 끄기, 음소거
- 테스트: `godot --headless res://tests/flow_test.tscn -- --flowtest`
- 개발용 URL: `index.html#ch2`, `#combat`, `#base`, `#nodialog`

## 메뉴 (터치)
- **타이틀**: 이어하기(가장 최근 저장) · 새 게임 · 불러오기 · 설정
- **설정**: 배경음악/효과음 볼륨(0–10), 텍스트 속도(느림/보통/빠름/즉시), 성장 방식(랜덤/고정), 전투 연출 — `user://settings.json`
- **저장/불러오기**: 자동 저장 1칸(장 시작·매 턴 시작·거점 진입) + 수동 3칸. 장·턴·플레이 시간·저장 시각·대표 유닛 표시,
  덮어쓰기/삭제 확인. 원자적 저장(임시 파일 → 이름 변경, .bak 복구). 거점 [저장], 전투 중 메뉴 [중단 저장] (전투 상태 그대로 재개).
- **전투 메뉴** (빈 칸 탭 또는 [메뉴]): 유닛 목록 · 전투 목표 · 설정 · 중단 저장 · 챕터 재시작(확인) · 타이틀로(확인) · 턴 종료
- **출전 준비** (매 장 시작, 1장은 도입 대화 후): 출전 유닛 선택(최대 인원, 아린 고정) · 아이템/장비/수송대 · 상태 · 시작. 지도에 배치 칸(파란색) 표시.
- **상태 화면** (유닛 길게 누르기, [상태], 각종 목록): 초상화, 이름·병종, Lv/EXP, HP, 8개 능력치 막대, 이동, 소지품 내구도,
  개인 스킬, 무기 종류, 각성/독/경계/보스 상태. 적에게도 사용 가능, ◀ ▶로 넘기기.
- 테스트: `godot --headless res://tests/menu_test.tscn -- --flowtest` (저장→불러오기 전투 복원, 슬롯 메타, 삭제, 설정)

## 무기 시스템
- **역할/효과** (`data/weapons.gd` TRAITS): 특효(위력×3: 중갑·기병·비행), 용사(2회 연속), 경량(무게 무시), 중량, 투척 1-2(투창·손도끼),
  마법검 윈드소드(1-2, 마력/마방), 킬러(치명+30), 지팡이 힐·멘드·피지오(사거리 1-4). 사용자 기본 14종 수치는 그대로, 활은 비행 특효.
- **병종 숙련** (`data/class_profs.gd`): 용병 검 명중+10, 기사 창 위력+1·명중+5, 도적 경량 검만·치명+10, 성기사 지팡이 회복+2, 상급직 확장.
- **무기 랭크 E–S**: 유닛별·종류별 무기 EXP(전투 +4, 회복 +5), 랭크 업 알림. 필요 랭크: 철 E, 강철 D, 킬러/특효 C, 은 B, 용사 A.
  보너스 C 명중+5 / B 위력+1 명중+5 / A 위력+2 명중+10 치명+5 / S 위력+3 명중+15 치명+5 (예측창 표시). 랭크 부족 무기는 회색+사유.
  세이브에 저장(`wexp`), 구 세이브는 병종 시작 랭크로 자동 이전. 병종 기본 능력치/성장률은 변경 없음.
- **아이콘**: 16×16 픽셀 무기 아이콘(종류별 형태 + 무기별 색) — 유닛 창, 예측창 양쪽, 출전 준비, 상태(랭크 글자), 아이템 목록, 상점.
- 2장 상점에 유틸 무기 추가, 2장 드롭: 아머킬러(중갑병)·투창·볼트·호스슬레이어(증원 기병)·보스 고유 「그림자 창 우르」.
- 테스트: `godot --headless res://tests/weapons_test.tscn -- --flowtest`

## 드롭 · 열쇠 · 아이템
- 랜덤 드롭: 적 처치 시 장비 무기 8% / 소지 아이템 5% (경계·정예 15% / 10%, 보스는 고정 드롭만). 장 시도마다 시드 고정 → 저장/불러오기·재시작으로 리롤 불가. 적 상태에 `드롭 ? 철도끼 8%` 표시.
- 열쇠: 문 열쇠(문 1개), 상자 열쇠(상자 1개), 마스터 키(문·상자 3회), 해제의 지팡이(5칸, 2회). 소지자 누구나 [열기] 가능, 도적은 무료(릴리/잭 보너스 유지). 상점에서 문/상자 열쇠 판매(2장~).
- 소모품: 상처약(HP10, 3회), 엘릭서, 능력치 아이템(힘의 반지·스피드링·여신의 상·드래곤 실드, 희귀). 전투 중 [아이템] 버튼으로 사용(행동 종료).
- 예측 창 무기 상성 ▲/▼, 메뉴 → [상성표].
