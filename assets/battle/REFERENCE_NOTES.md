# GBA 파이어엠블렘(6·7·8) 전투 화면·아이콘 참고 메모

참고만 하고 그림은 전부 새로 그렸다. 원작 그림을 뽑아 쓰지 않았다.
- 아이콘: `tools/make_icons.py`
- 배경과 발판: `tools/make_battle_bg.py`

## 전투 화면 구조 (GBA 240x160)
- **화면 크기**: GBA 화면은 240x160이다. 원작 전투 틀은 흔들림 여유 때문에 가로 256px로 만든다.
- **위쪽 이름판**: 왼쪽이 적, 오른쪽이 아군이다. 이름판 옆에 무기판이 붙는다. 무기판에는 16x16 아이콘과 무기 이름이 들어간다.
- **아래 창**: 진영마다 하나씩, 아군은 파랑, 적은 빨강이다.
  - 바깥쪽에 HIT, DMG, CRT 칸이 있다.
  - 그 아래에 큰 HP 숫자와 칸 나뉜 HP 막대가 있다. 막대는 1칸이 HP 1이고, 한 줄을 넘으면 두 줄로 이어진다.
  - 연속 공격이면 x2를 표시한다.
- **무대**: 지형별 배경(평원, 숲, 요새·성, 마을, 사막, 설원, 산) 위에 각 유닛이 지형 발판을 밟고 선다.
  - 근접 공격이면 두 발판이 붙어 있다. 원거리 공격이면 서로 떨어진다.
  - 아군은 오른쪽에서 왼쪽을 보고, 적은 왼쪽에 선다.
- **상성 표시**: 무기 상성은 아이콘 옆의 화살표로 보여준다. 이 게임에서는 ▲유리, ▼불리로 쓴다.

## 아이템 아이콘 관례 (16x16)
- **종류별 실루엣**: 종류마다 모양이 확실히 다르다. 검·창·도끼·활은 대각선 방향이다.
  - 검: 가는 날, 날밑, 손잡이
  - 창: 긴 자루와 잎 모양 촉
  - 도끼: 짧은 자루와 부채꼴 날
  - 활: D자 모양에 시위가 있다
- **등급은 같은 모양에 색과 장식으로 구분한다**:
  - 철: 회색
  - 강철: 더 어둡고 두꺼움
  - 은: 밝은 흰빛에 광택
  - 킬러: 붉은 날끝이나 보석, 술 장식
  - 용사: 금빛에 날이나 촉이 두 개
  - 특효 무기: 날 모양을 바꾸거나(넓은 날, 갈고리) 초록 날을 쓴다
- **마도서**: 책 모양은 같고 표지 색과 문양으로 속성을 나타낸다. 불은 빨강에 불꽃, 번개는 노랑에 번개, 바람은 초록에 소용돌이, 빛은 흰색과 금색에 빛살, 어둠은 보라에 눈 문양이다.
- **지팡이**: 긴 자루 끝에 머리 장식이 달린다. 힐은 금고리, 멘드는 파란 구슬과 날개, 피지오는 초록 별, 해제는 열쇠 모양이다.
- **소모품**: 상처약과 엘릭서는 약병, 문·상자·마스터 키는 열쇠 모양이다. 능력치 아이템은 반지, 여신상, 방패로 그렸다.

## 이 게임에서 정한 것
- **확대 배율**: 아이콘은 16x16 원본을 정수 배율로만 키운다(16, 32, 48, 64). 배경은 3배(720x480), 발판은 64x16을 3배로 그린다.
- **상성 색 타일**: 검·창·도끼 아이콘은 상성 색 타일 위에 올린다. 검은 파랑, 창은 초록, 도끼는 빨강이다(`Icons.TRI`).
- **세로 화면 배치**: 720 단위 화면(폰 390x844)에서는 GBA처럼 이름판, 무대(240x160 x3), 아래 창 순서로 세로로 쌓는다.
  - 위쪽 여백은 노치를 피하도록 `safe area`와 화면 중앙 정렬 중 큰 값을 쓴다.
  - [건너뛰기 ▶▶] 버튼은 아래 창 밑에 둔다.
